# 🚗 BPark – Parking Management System

BPark is a client-server parking management system developed in **Java**, designed to simplify and manage parking operations with separate interfaces for administrators and workers.

---

## 📋 Overview
The system enables efficient management of parking spaces, users, and subscriptions through a structured client-server architecture.

---

## 🚀 Features
- Client-server architecture for managing parking operations  
- Separate interfaces for administrators and workers  
- Vehicle entry and exit management  
- Parking slot allocation and tracking  
- User and subscriber management  
- Confirmation code verification  
- Reporting and data tracking  

---

## 🛠️ Technologies
- Java  
- JavaFX  
- Scene Builder  
- MySQL  
- SQL  
- Local Storage  
- Object-Oriented Programming (OOP)
